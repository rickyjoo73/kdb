# KDB 요청 계약 (Request Contract) v1.0 — 소비자 필수 준수

**대상**: kstory · issuetalk · trendbiz · 미디어파인 등 KDB API 소비자 전체
**제정**: 2026-07-16 (오너 지시) · **성격**: 권장이 아니라 **계약**입니다.

KDB의 처리 속도·정확도는 요청 품질이 결정합니다. 불명확한 키워드는 보류 큐에 쌓여
그 소비자의 처리만 늦어지고, 잘못된 타입은 DB를 오염시킵니다(실측: 가수를 song_album
으로 보낸 요청이 가수 엔티티를 곡으로 굳힘). **아래 필수 필드를 갖추도록 시스템을
세팅하세요. 준수율은 소비자별로 측정되어 admin 대시보드에 공개됩니다.**

## 1. 필수 필드 (모든 /v1/prepare · /v1/lookup 요청)

| 필드 | 필수 | 규칙 |
|------|------|------|
| `query` | **필수** | 고유명사 **원형 1개만**. 기사 표기 그대로. 조합어·수식어·병기 금지 (§3) |
| `type` | **필수** | §2 판별표로 기사에서 판별해 지정. 판별 불가 시에만 `unknown` — 이 경우 `context_hint` 없으면 저품질 레인 |
| `context_hint` | **필수** | 키워드가 등장한 **기사 문장 1개**(±200자). 동명이인 구분의 핵심. 키워드 반복·본문 전체 금지 |
| `source_url` | **필수** | 키워드가 나온 기사 URL. 신뢰 매체면 게이트 통과 가속 |
| `origin` | **필수** | `lookup-miss`(지금 번역에 필요) 또는 `prepare`(사전 준비). lookup-miss 가 우선 처리됨 |

## 2. 타입 판별표 — 기사 단서 → type

시스템이 기사에서 아래 단서를 보고 기계적으로 판별하도록 구현하세요.

| 기사 단서 | type |
|----------|------|
| "배우/가수/래퍼/개그맨/PD ○○" , "그룹 △△의 멤버 ○○" (실존 인물) | `person` |
| "그룹/밴드/듀오/팀 ○○" | `group` |
| "드라마 ○○" , 방영·회차·시청률 문맥 | `drama` |
| "영화 ○○" , 개봉·관객수 문맥 | `movie` |
| "예능/프로그램/방송 ○○" | `show` |
| "곡/신곡/타이틀곡/앨범 ○○" , 발매·수록 문맥 | `song_album` |
| "시상식/콘서트/투어/페스티벌 ○○" | `event_tour` |
| "소속사/기획사/제작사 ○○" | `agency` |
| "채널/매체/플랫폼 ○○" | `channel_outlet` |
| 상표·장소·시설 | `brand_place` |
| 드라마 속 **배역 이름** (실존 인물 아님) | `character` |
| 위 어느 것도 판별 불가 | `unknown` + context_hint 필수 |

★혼동 주의: **사람 이름은 그의 곡·작품이 아니라 person**입니다. 실존 인물은 character가
아닙니다. "가수 박학기의 신곡 '바람이 분다'" → 박학기=person, 바람이 분다=song_album 두 건.

## 3. 보내면 안 되는 것 (서버가 기각·차단)

- **조합어/수식어**: `아이유 콘서트 티켓`(×) → `아이유`(person) / `배우 아이유`(×)
- **일반명사·카테고리**: 배우, 아이돌, 컴백, K-POP(장르어) — `category_not_entity` 기각
- **광고·상거래 키워드**: ○○광고, ○○예매, ○○할인, ○○다시보기 — `commodity_term` 즉시 기각 (2026-07-16부터)
- **기사 명사 전체 투척**: 번역에 실제 필요한 고유명사만. 목록 통짜는 보류만 쌓임
- **같은 키워드 수 분 내 반복**: miss 응답=`preparing`(발굴 중, 평균 15초) → 재조회가 정답

## 4. 요청 예시

```json
POST /v1/prepare
{"items":[
  {"query":"박학기","type":"person",
   "context_hint":"가수 박학기가 신곡 '바람이 분다'를 발표했다",
   "source_url":"https://news.example.com/a/123","origin":"prepare"},
  {"query":"폭싹 속았수다","type":"drama",
   "context_hint":"드라마 '폭싹 속았수다'가 시청률 1위를 기록했다",
   "source_url":"https://news.example.com/a/124","origin":"lookup-miss"}
]}
```

## 5. 미준수 시 처리 (서버 동작)

- type·context 없는 키워드 → 심사 게이트 보류(저품질 레인) — **처리 수 시간 지연**
- 광고·일반어 → 즉시 기각, 반복 시 소비자 노이즈 지표만 상승
- 잘못된 type → KDB가 기사 재검색으로 재판정(type-retrace)하지만 이는 이중 비용 —
  **준수율이 낮은 소비자는 우선순위가 밀립니다**

## 6. 응답 활용 규칙 (기존과 동일)

- 번역힌트 자동 채택: `operator_locked=true` 또는 `confidence>=0.9`만
- `provenance=machine-translation` 값은 폴백 — 주기 재조회로 공식 표기 갱신
- `status=rejected` 키워드 재요청 금지, 이의는 `/v1/corrections`
