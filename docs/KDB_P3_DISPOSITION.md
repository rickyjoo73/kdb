> 이 절의 앞 판(검증 표기 242건)은 **상류 원천 정책이 승인되기 전**의 값이었다.

**무엇이 바뀌었나.** 표기는 TDB 가 만든 것이 아니라 상류 원천(aihub_tour · 공공누리 · CC0)에서
온다. G3 시점에는 그 원천들의 정책이 승인돼 있지 않아 **보관은 하되 공급하지 않았다**(기본 차단, S03).
2026-09-14 운영자가 사용 가능을 확인했고(“TDB 사용해 추후 더 모아 학습 사용할 거야.
사용 가능하니 너가 판단하지 마.”), 0128 이 14개 상류 원천 정책을 라이선스와 함께 승인했다.
그 뒤 흡수 표기 536,079건을 검증 승격했다.

**근거는 지어내지 않았다.** 표기마다 `claim_type='name'` 근거를 한 행씩 새로 적되,
`source_record_id`·`source_url`·`source_observation_hash` 는 **흡수 당시 관측자가 실제로 기록한
identity 근거에서 그대로** 가져왔다. 관측하지 않은 값을 채워 넣는 것이 D-37 의 실패였고,
같은 실수를 반복하지 않는다. 검증 주체는 `policy:tdb-absorption-name-v1` 로 남겨
**사람이 한 건씩 본 것이 아니라 정책 승인으로 올렸다는 사실**을 소비자가 API 에서 볼 수 있다
(`verification_method` 필드).

**승격하지 않은 7건.** `form='unknown'` 4건(표기 형식을 모른다 — 권리 문제가 아니다)과
근거가 아직 `unverified` 인 wikidata-label 3건이다. 건수를 채우려고 끼워 넣지 않았다.

**남은 한계 — 원천 URL.** 근거의 `source_url` 은 우리 원장의 위치를 가리킨다. 상류 원천의
실제 페이지 주소는 흡수 시점에 관측되지 않았으므로 비어 있고, **지어내지 않는다.**
원천 URL 보충은 P4 의 일이다.
