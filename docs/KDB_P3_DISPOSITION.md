## 4. ★ 실제 사용 가능 수 — 등록 수와 다르다

| 항목 | 수 |
|---|---|
| 공통 원장 **등록** | 555,869 (TDB 536,322 + 기존 KDB 19,544 + 신규 3) |
| **검증된 표기(소비자에게 공급 가능)** | **242** |
| 보관만 된 표기(`unverified`) | 536,082 |
| `active` 상태 흡수분(서빙 후보) | **0** |

**왜 242 뿐인가.** 표기는 TDB 가 만든 것이 아니라 상류 원천(aihub_tour · 공공누리 · CC0)에서
온다. 그 원천의 정책이 승인되기 전까지는 **보관은 하되 공급하지 않는다**(기본 차단, S03).
242건은 admin_region 파일럿에서 wikidata(CC0, 승인됨) 표기를 쓴 것이다.

정책이 승인되면 그때 검증 승격한다. 지금 이 숫자를 "53만건 준비 완료"로 말하지 않는다.
