## ★알려진 오탐 — 문맥 추출의 `제목(아티스트)` 패턴

```
그대만을 → 015B     ← 015B 는 제목이 아니라 가수다
```

기사가 「그대만을(015B)」로 쓰면 괄호 안을 외국어 표기로 읽는다. 합의 게이트(독립
매체 2곳)가 승급을 막아 주므로 당장 피해는 없지만, 가드를 넣는 게 맞다. 후보:

- 괄호 안이 **active 인물/그룹 이름과 일치**하면 버린다 (가장 확실)
- 숫자로 시작하는 짧은 토큰(015B, 2NE1 …)은 아티스트일 확률이 높다 — 단, 제목일
  수도 있어서(`20's Party 1` 이 정상 추출이었다) 이것만으로 버리면 안 된다
