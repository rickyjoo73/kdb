## 4. 설계 — 4층 구조 (대부분 이미 있었다)

```
1층  채운다              llm-provisional (prio 9)        ★신규, 배포됨(스위치 꺼짐)
2층  등급을 알려준다      LocaleProvenance "llm-only"     ◐ 있으나 요청해야 나옴
3층  그쪽 값을 받는다     POST /v1/observations
                        + media-consensus 승급           ✅ 이미 있음
4층  대조 판정 회신                                       ☐ 미구현
```

### 3층이 이미 정교하다 — 새로 만들지 말 것

`observations.go` 의 `EvaluateConsensus`:
- 같은 normalized spelling 의 **distinct parent_org** 수 + trust×confidence 가중
- 같은 URL 하나가 여러 매체로 세어지던 버그까지 이미 고쳐져 있음(2026-09-15)
- 48시간 promote 쿨다운

### 4층이 해야 할 판정 (오너가 말한 부분)

```
우리 authoritative + 그쪽 다름      →  "우리 것이 맞다" + 근거 URL 회신
우리 잠정 + 그쪽 다름               →  검증 큐 최상위. 답은 "확인 중"
우리 잠정 + 여러 소비자가 같은 값     →  그 값으로 승급 (consensus)
우리 빈칸 + 그쪽 값 있음             →  후보로 접수
```
